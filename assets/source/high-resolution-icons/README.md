# Original 64px render provenance

`provenance.json` pins the source image archive/database and unchanged published
dataset manifest, and lists all generated companion assets. Original PNGs remain
in the private validated GTNH export; the source archive is not redistributed.
Selected public sprites are losslessly packed from those originals. Their
underlying Minecraft/mod artwork retains its original ownership and terms, as
with the existing 32px recipe-browser sprites. No source image is upscaled.

See `docs/icon-resolution.md` and `tools/high-resolution-icons/` for recovery,
building, pixel validation, identity handling and runtime fallback behavior.
